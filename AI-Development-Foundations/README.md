## About This Repository

This repository contains the **complete training documentation** for **Superskill #1 — AI Development Foundations, Ethics & Setup**, the first of **44 superskills** in the AI Developer Bootcamp.

The superskill covers **11 core skills** plus a **conclusion**, taking you from _"what is AI?"_ to _"how do I think like an AI product builder?"_ — before a single line of AI code is written.

Each skill is delivered as a **standalone Markdown training document**, structured for progressive learning from **beginner → intermediate → junior developer**.

---

## Who This Is For

| Audience                   | Why it fits                                              |
| -------------------------- | -------------------------------------------------------- |
| **Web developers**         | Solid software fundamentals, moving into AI development. |
| **Self-taught developers** | Want a structured, professional-quality curriculum.      |
| **Junior developers**      | Preparing for their first AI-focused role.               |
| **Anyone curious**         | Prefer to _understand_ AI deeply before _using_ it.      |

> **No AI background required.** Familiarity with web development concepts (APIs, request/response, environment variables) is helpful but not mandatory.

---

## What You'll Learn

By the end of this superskill, you will be able to:

- ✅ Explain **what AI is** — and how Machine Learning and Deep Learning nest inside it.
- ✅ Distinguish **AI Development** from Data Science and ML Engineering.
- ✅ Trace the **four-decade arc** from rule-based AI to generative AI.
- ✅ Describe an **LLM** as a next-token predictor — without hand-waving.
- ✅ Work with **tokens**, **context windows**, **inference**, and **temperature**.
- ✅ Identify where AI **genuinely earns its keep** in business.
- ✅ Recognise and guard against **hallucination, bias, privacy risks, prompt injection, and PII**.
- ✅ Apply **product thinking** — the six questions, the MVP habit, and scoping discipline.

## How to Use This Repository

### As a learner

1. **Read the skills in order.** Each one builds on the previous.
2. **Do the exercises.** Every doc ends with hands-on work and checkpoint questions.
3. **Don't skip the worked examples.** They're the bridge from concept to practice.
4. **Re-read before the project.** The six questions in Skill 11 map directly to the project brief.

### As a reference

- Each document is **self-contained** — you can jump to any skill if you need a refresher.
- **Tables and comparison matrices** are designed for quick scanning.
- **Pitfalls sections** are short, concrete checklists you can return to while building.
