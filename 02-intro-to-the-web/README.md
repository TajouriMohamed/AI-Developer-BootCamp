## About This Repository

This repository contains the **complete training documentation** for **Superskill #2 — Intro to the Web**, the second of **44 superskills** in the AI Developer Bootcamp.

The superskill covers **10 core skills**, taking you from _"what's the difference between the Internet and the Web?"_ to _"I've created my first web page and my GitHub account."_ It's the foundation for everything that follows: HTML, CSS, JavaScript, the DOM, and eventually the AI development work of later superskills.

Each skill is delivered as a **standalone Markdown training document**, structured for progressive learning from **beginner → intermediate → junior developer**.

---

## Who This Is For

- **Web developers** with solid software fundamentals who want to move into AI development.
- **Self-taught developers** who want a structured, professional-quality curriculum.
- **Junior developers** preparing for their first AI-focused role.
- **Anyone** who wants to understand how the Web actually works — not just how to use it.

> **No AI background required.** Familiarity with web development concepts (APIs, request/response, environment variables) is helpful but not mandatory.

---

## What You'll Learn

By the end of this superskill, you will be able to:

- ✅ Distinguish **the Internet** (infrastructure) from **the Web** (content), and explain how they relate.
- ✅ Describe **web architecture** — clients, servers, and the request/response cycle between them.
- ✅ Explain **Internet protocols** and how **HTTP** drives the Web.
- ✅ Work with **servers and APIs** — including **REST** constraints and the full set of **HTTP methods**.
- ✅ Understand **databases** — the difference between **SQL** and **NoSQL**, and what a **DBMS** does for you.
- ✅ Define **web development** and the **three layers** — front-end, back-end, database — plus the **three pillars** (HTML, CSS, JavaScript).
- ✅ Build a website with a **CMS** (WordPress, Prestashop, etc.) and understand **when to choose CMS vs. hard coding**.
- ✅ Set up your **developer environment** — VSCode, Chrome, extensions, and a first HTML page.
- ✅ Create a **GitHub account** and understand how it relates to **Git** and **version control**.

## How to Use This Repository

### As a learner

1. **Read the skills in order.** Each one builds on the previous.
2. **Do the exercises.** Every doc ends with hands-on work and checkpoint questions.
3. **Don't skip the worked examples.** They're the bridge from concept to practice.
4. **Bookmark the skill index.** It's your table of contents when you need a refresher.

### As a reference

- Each document is **self-contained** — you can jump to any skill if you need a refresher.
- **Tables and comparison matrices** are designed for quick scanning.
- **Pitfalls sections** are short, concrete checklists you can return to while building.

### As an instructor

- Each skill doc includes **checkpoint questions** you can use for assessment.
- The **hands-on exercises** are sequenced — they build on each other across skills.
- The **worked examples** are self-contained and can be assigned as reading.
